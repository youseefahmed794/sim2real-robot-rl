## 2. Withdrawn interpretations

The saved PPO runs used a backend without optimizer updates. Their tables are
preserved for provenance, but claims about PPO convergence, locomotion learning,
training-budget sufficiency, or the benefit of Domain Randomization are withdrawn.
The numerical table has not been regenerated by this repair.

The analytical baseline is a separate method. Its historical numbers are retained;
this repair does not independently reproduce or validate them.

## 3. Current validation boundary

The repair validates shared PPO gradients, optimizer steps, checkpoint resumption,
and a one-step contextual-bandit learning gate. It does not establish quadruped
locomotion, sim-to-sim generalization, or physical hardware transfer.
See [the repair record](PPO_REPAIR.md).
